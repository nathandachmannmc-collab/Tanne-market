Warten auf freigegebenen Marktdatenzugriff

Die Quellen zeigen ihre Live-Ansichten in ihren eigenen Websites, aber unser unabhängiger Abruf erhielt HTTP 403. Ohne einen von den Betreibern freigegebenen Feed oder API-Zugang können wir echte Auktionen nicht zuverlässig importieren.
Das bedeutet nicht, dass auf Hugo SMP keine Auktionen existieren. Nur unser automatischer Datenabruf bekommt aktuell keine Daten zurück.

Technische Details anzeigen

Geprüft wurden die öffentlich sichtbaren Live-Seiten sowie ein Abruf der Seiten und ihrer öffentlich referenzierten Skripte aus GitHub Actions mit normalen Browser-Headern. Beide Hauptseiten antworteten mit HTTP 403; daher standen in diesem Test keine Client-Skripte oder API-Endpunkte zum Auswerten bereit.

Der nächste technische Schritt benötigt eine offizielle API, einen öffentlichen JSON-/WebSocket-Feed oder eine Freigabe der Betreiber. Der HTTP-403-Status wird nicht umgangen.
